# 토닥 (Todak) — 설치본

바탕화면에서 포켓몬 도트가 돌아다니는 작은 앱 (Windows · 맥). **이 저장소에는 설치본만 있다.**

> 👉 **[여기서 최신 설치본 받기](../../releases/latest)** — 한 번 깔면 그 뒤로는 앱이 알아서 새 버전을 받는다. 다시 받으러 올 일이 없다.

---

## 🪟 Windows 설치 방법

### 1. 설치 파일 받기
[최신 릴리스](../../releases/latest) 맨 아래 **Assets** 에서 `todak-setup-<버전>.exe` 를 누른다.

### 2. 브라우저가 「위험할 수 있다」고 하면 → **유지**
코드 서명(유료 인증서)을 안 해서 브라우저가 한 번 막는다. 파일은 그대로 두면 된다.

- **크롬** — 다운로드 목록에 「일반적으로 다운로드되지 않는 파일」이 뜨면
  파일 옆 **[⋮]** 또는 경고 안의 **[유지]** → **[그래도 유지]**
- **엣지** — 오른쪽 위 다운로드 창에서 파일에 마우스를 올리고 **[⋯]** → **[유지]** →
  **[자세히 표시]** → **[그래도 유지]**

### 3. 파란 창 「Windows의 PC 보호」가 뜨면 → **추가 정보 → 실행**
받은 파일을 실행하면 SmartScreen 이 한 번 막는다.
글자 **[추가 정보]** 를 누르면 아래에 **[실행]** 버튼이 생긴다.

### 4. 끝
설치 창 없이 바로 깔리고 실행된다. 처음에는 **첫 친구를 고르는 창**이 뜬다.
- 바탕화면 아래쪽에 포켓몬이 나온다 — 쓰다듬고(문지르기) 들어서 옮길 수 있다
- 오른쪽 아래 **트레이**(`^` 숨은 아이콘 안)에 토닥 아이콘이 있다 → **우클릭**하면 메뉴 · **더블클릭**하면 도감 창
- 컴퓨터를 켤 때 같이 켜지게 하려면: 트레이 → **⚙️ 자잘한 설정 → 「시작할 때 자동 실행」** 체크

## 🍎 맥 설치 방법 (Apple 실리콘 · M1 이상)

### 1. 설치 파일 받기
[최신 릴리스](../../releases/latest) 의 **Assets** 에서 `todak-<버전>-arm64.dmg` 를 받는다.

### 2. 응용 프로그램 폴더로 끌기
dmg 를 열고 **Todak** 을 **응용 프로그램(Applications)** 폴더로 끌어다 놓는다.
⚠ 꼭 응용 프로그램 폴더에서 실행해야 자동 업데이트가 된다 (dmg 안에서 바로 열지 말 것).

### 3. 처음 열 때 「확인되지 않은 개발자」라고 막으면
- **Finder** 에서 Todak 을 **우클릭 → [열기]** → 다시 **[열기]**
- macOS 15 이상이면: **시스템 설정 → 개인정보 보호 및 보안** → 아래로 내리면 「Todak 이(가) 차단되었습니다」 옆 **[그래도 열기]**
- 그래도 「손상되었기 때문에 열 수 없습니다」가 뜨면 **터미널**에 아래 한 줄을 붙여 넣고 다시 연다:
  ```
  xattr -dr com.apple.quarantine /Applications/Todak.app
  ```

## ❓ 자주 묻는 것

- **바이러스 아니야?** — 서명 인증서(연 수십만 원)를 안 사서 뜨는 경고다. 친구들끼리 쓰는 비상업 앱이라 서명을 안 했다.
- **업데이트는?** — 앱이 켜져 있으면 알아서 받아 두고, 자리를 비운 사이에 조용히 바꾼다. 트레이 → 「지금 업데이트 확인」으로 바로 받을 수도 있다.
- **작업 방해 안 해?** — 클릭은 포켓몬 몸 위에서만 먹는다. 전체화면 게임·발표·방해 금지 중에는 스스로 물러난다. 트레이 → ⚙️ 자잘한 설정에서 **투명도·크기**를 줄일 수 있다.
- **지우려면?** — Windows: 설정 → 앱 → 「토닥」 제거 · 맥: 응용 프로그램에서 Todak 을 휴지통으로.

---

## 이게 뭔가

- 투명·클릭통과 오버레이 위에서 포켓몬이 걷고, 쓰다듬어지고, 창 테두리에 올라선다
- 함께 있으면 레벨이 오르고 진화한다 · 야생을 만나고 도감을 채운다
- 전체화면 게임·발표·방해 금지 중에는 **스스로 물러난다**
- 무엇을 하고 있는지는 **알지 못한다** — 창 제목도 프로그램 이름도 키 입력도 읽지 않는다

## 라이선스 / IP

**개인·비상업 팬 프로젝트다.** 포켓몬 관련 IP 는 Nintendo / Creatures / GAME FREAK 소유다.
판매하지 않고, 스토어에 올리지 않고, 후원도 받지 않는다.
권리자의 요청이 있으면 내린다.

스프라이트는 PokeAPI 의 공개 미러에서 가져온다. 앱 소스는 비공개다.
